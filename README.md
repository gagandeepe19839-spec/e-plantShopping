
# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is an online plant shopping application that allows users to explore houseplants, view their prices, and add plants to a shopping cart.

## Features
- Attractive landing page with a Get Started button.
- About Us page describing the company.
- Plant products organized into categories.
- Add to Cart functionality.
- Dynamic shopping cart item count.
- Increase or decrease plant quantities.
- Remove items from the cart.
- Automatic calculation of item totals and the overall cart amount.
- Continue Shopping and Checkout options.

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- React Router
